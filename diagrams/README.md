# 架构图说明

六张图均提供 **可编辑的 DOT 源码**（`.dot`）、矢量图（`.svg`）和位图（`.png`），使用 Graphviz 生成：

```powershell
dot -Tsvg -o diagrams/01_系统全景.svg diagrams/01_系统全景.dot
```

1. 系统全景：Shell / Gateway / Core / 服务 / 插件与横切诊断。
2. 模块依赖：允许调用的逻辑方向。
3. 编辑操作序列：成功、冲突、未知保存状态与审计。
4. 工作区布局：多视图共享单一 Document Session。
5. 工程路线：F0、P0、E01～E09 的依赖次序。
6. 诊断链路：异常记录/诊断与恢复。

图是**规划概念**，不是已经运行的实现拓扑。若修改契约，需同步更新图/文档/ADR。
