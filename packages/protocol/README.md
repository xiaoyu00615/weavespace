# protocol（协议边界常量）

## 职责
Host 与 Shell 之间**必须一致**的协议常量，以及由这些常量导出的纯函数。
放这里的唯一理由：两侧各写一个"看起来一样"的数字，迟早会不一致，而错位的
后果是整批请求被拒（一条都没生效），且失败点离用户很远。

## 公开接口（`index.ts`）
- `MAX_RECLAIM_PATHS` → `POST /api/views/reclaim` 单次最多接受的路径数（64）
- `chunkReclaimPaths(paths, limit?)` → 按上限切批（不排序、不去重、不改写路径）

## 数据所有权
不拥有任何数据。这里没有 IO、没有状态、没有授权判定——只有常量与切分规则。

## 边界
- 不得依赖 `apps/` 或 `plugins/`（ENG-001）。
- 不得把"业务语义"塞进来：去重、排序、优先级都属于调用方。
