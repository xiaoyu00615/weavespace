# F0 基线状态与决策范围

**版本**：v0.2 | **日期**：2026-11-10 | **状态**：待正式签收的 F0 架构提案（不是冻结基线）。

## 已在讨论中明确的产品意图（共识）

1. 本地优先；桌面环境通过 localhost Web 工作台使用；未来通过 LAN / 远程授权访问。
2. UI 是 Shell：项目导航、文件树、文件专属菜单、主视图、可折叠辅助面板。支持单视图、左右/上下分屏及后续自由组合。
3. 功能由插件扩展；扩展名只是选择候选处理器的依据，不限制“同一扩展名只能有一个插件”。支持自定义格式与结构化画布。
4. 文件解析 / 预览 / 编辑 / 保存解耦；可由不同插件分别提供；AI 不是必需运行条件。
5. 内置 AI 与外部 AI（DSH/GPT/WorkBuddy/未来 LAH）可通过受控命令操作局部、文件、文件夹、项目。
6. 模块独立目录、公开契约、底层数据结构先行；必须有时间戳日志、Trace、审计、故障诊断和恢复测试。
7. 两电脑 Git/GitHub 研发；远程 GitHub、云盘、LAN 共享先留扩展边界，不急于实现。
8. 为首版选择真实影视项目资产作为验收场景，但不把产品限定为影视行业。

## 尚未批准/需要验证的技术假设

| 议题 | 当前候选 | 决策前必须验证 |
|---|---|---|
| 名称 | **织界（WeaveSpace）** / `weavespace` | 用户已选择产品名称；商标、域名和名称冲突尚未核验 |
| 前端 | React + TypeScript | 分屏插件挂载/卸载、Document Session 共享 |
| 后端 | Node.js + TypeScript | 本地权限与 IPC、安全退出、异常恢复 |
| 数据库 | SQLite（单宿主权威） | WAL、备份、迁移与多客户端写入协同 |
| 插件容器 | 优先技术验证 Cordis；或自研极简接口 | 服务依赖、故障清理、信任隔离、升级成本 |
| 画布 | React Flow + ELK.js | 自定义节点、布局及稳定保存行为 |
| 文档解析 | JS 原生解析 + 可选 Python sidecar（Docling） | 安装体积、Windows 可用性、隔离与故障回传 |
| 项目文件 | `.wcanvas` / `.wproject`（候选） | 格式版本、迁移、相对路径、安全规则 |
| 网络 | HTTP API / MCP 适配器 / SSE 事件 | 授权隔离、断线重同步与只读默认 |

**管理原则**：F0 先冻结“不变量与职责边界”；技术框架和 API 签名只有通过 P0 原型验证后才能签收。任何改变须留 ADR。
