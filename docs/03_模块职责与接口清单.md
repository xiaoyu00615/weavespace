# 模块职责、公开接口和依赖方向

**原则**：按数据所有权/业务责任划分模块；每个模块只暴露一个公共导出面。以下目录是逻辑结构，P0 可合并为少量包，不要机械创建几十个空包。

| 逻辑模块 | 数据/能力所有者 | 公开接口草案 | 禁止承担 |
|---|---|---|---|
| `contracts` | 契约及协议版本 | 类型、Schema、error codes | 数据库访问、业务逻辑 |
| `resource` | 稳定资源 ID / URI / 文件引用映射 | `resolve`, `stat`, `lookup` | 编辑器渲染 |
| `storage` | 本地 / 远程文件内容读写 | `list`（递归，旧端点冻结）、`readDir`（**只取一层**，UX-02B-TREE）、`read`, `writeConditional`, `watch` | UI 与关系提取 |
| `document` | 文档会话 / dirty / 版本 / 保存 | `openSession`, `applyEdit`, `save`, `recover` | 任意 AI 工具执行 |
| `plugin-runtime` | 插件清单/依赖/激活/清理 | `register`, `activate`, `deactivate`, `status` | 任意直接存储访问 |
| `command` | 统一命令、输入检验、去重/结果 | `dispatch`, `getResult`, `dryRun` | 实际格式编码 |
| `permission` | actor、scope、授权策略、审计判定 | `authorize` | 解析文件正文 |
| `workspace` | 布局树/标签与视图实例 | `openView`, `split`, `restore` | 文档内容副本 |
| `jobs-events` | job 状态 / 进度 / 可恢复事件通知 | `schedule`, `cancel`, `subscribe`, `snapshot` | 业务数据库写入 |
| `knowledge-index` | Derived 索引、实体/来源 | `index`, `search`, `relations` | 覆盖 Authored |
| `observability` | 时间、trace、日志、健康/诊断 | `log`, `trace`, `incident` | 作为真实业务状态源 |
| `gateway` | 本地 API、未来 LAN/MCP 适配 | `request`, `subscribe` | 直接修改插件私有状态 |
| `ai-context`（后续） | scope 选择、上下文构建与费用预算 | `assemble`, `estimate`, `propose` | 默认自主保存文件 |

## 依赖约束

1. 业务插件只依赖 `contracts` 与所需公共能力 token，不直接引用另一插件内部路径。
2. `contracts` 不反向依赖任何具体实现；从底层向 UI 反向引用违反架构。
3. UI 可使用 Client Facade，但不得连接 SQLite、操作本机绝对路径或直接加载 Node 特权模块。
4. 权限服务是统一写入和远程读取的门禁；插件 manifest 声明权限≠已经授权。
5. Storage Provider 负责实际读写；Document Service 负责编辑会话、冲突协调。不要在每个插件中再造保存/锁实现。
6. SDK 版本与文件格式版本独立。升级一方不应隐式升级另一方。

## 公开调用链示例

用户 UI / 外部 AI → Gateway/Façade → Command.dispatch → Permission.authorize → Document.applyEdit → Serializer → Storage.writeConditional → Audit/Event → UI 刷新。

## 分模块源码目录样板

```text
apps/web/                     # Shell 与 Client API，禁止直接 Node fs
apps/server/                  # localhost Host API 入口
packages/contracts/           # 数据结构、错误代码、Schema
packages/core/                # 服务组合（薄层）
packages/resource/            # 统一资源
packages/storage/             # StorageProvider 接口 + LocalProvider
packages/document/            # Document Session + 保存
packages/plugin-runtime/      # 插件运行生命周期
packages/command/             # 命令与授权调度
packages/permission/          # 权限与 actor
packages/workspace/           # 分屏树、视图注册
packages/observability/       # 日志/trace/诊断
packages/jobs/                # 后台任务与事件
packages/knowledge/           # 后期索引知识
plugins/markdown/             # manifest/parser/editor/view/serializer
plugins/image-viewer/         # manifest/viewer
plugins/weavespace-canvas/         # manifest/model/editor/view
```

具体目录在 P0 技术选型后建立，不提前填入无用的占位业务文件。
