# 核心数据模型与协议约束

## 数据分层（不能混淆）

- **Source**：原始可定位资源，底层格式与 Storage Provider 所有；可能是只读、远程或虚拟的。
- **Session**：当前编辑缓冲及未保存内容。它可能领先于磁盘版本；同一文件多视图共用会话。
- **Derived**：解析结果、全文索引、AI 候选知识，可按文件哈希/插件版本/规则版本重建。
- **Authored**：用户创建或确认的关系/画布/备注，不能因重建 Derived 直接覆盖。
- **Presentation**：布局、缩放、标签等 UI 状态，按项目及用户保存。
- **Runtime/Audit**：任务/命令事实与审计事件；不将调试日志误作事务日志。

## 全局身份与版本

- `resourceId`：稳定的资源身份，不以 Windows 绝对路径作为唯一 ID；重命名/移动尝试保持映射，不能确定则标记待确认。
- `resourceUri`：可定位方式，由 Provider 解释；**不是**授予访问权限的凭据。
- `contentVersion`：可比较的版本 token/ETag/hash，不应单凭本地时间判断。
- `documentSessionId`：编辑器会话实例；一个资源可能有多个打开视图，但首版单一写入权威。
- `viewId`：独立视图实例；不同于源文档。
- `actorId`：人/外部 Agent/内部任务的授权主体；不直接信任客户端声称的 `actorId`，由 Gateway 验证绑定。
- `operationId`/`idempotencyKey`/`traceId`：分别是操作身份/幂等/追踪身份；不可混为同一字段。
- `sequence`：仅在指定的权威事件流或资源版本域内有意义，不是跨设备全局时钟。

## 核心模型（伪 TypeScript，非最终 SDK）

```ts
interface ResourceRef { resourceId: string; uri: string; providerId: string; contentVersion?: string }
interface DocumentState { sessionId: string; resourceId: string; baseVersion: string; revision: number; dirty: boolean }
interface CommandEnvelope<T = unknown> { commandId: string; idempotencyKey?: string; type: string; expectedVersion?: string; target?: ResourceRef; payload: T }
interface CommandResult<T = unknown> { commandId: string; status: 'APPLIED'|'REJECTED'|'FAILED'|'UNKNOWN'; result?: T; errorCode?: string; resultingVersion?: string }
interface EventEnvelope<T = unknown> { eventId: string; streamId: string; sequence: number; occurredAt: string; traceId: string; type: string; data: T }
```

`UNKNOWN` 用于请求超时/连接断开但副作用结果未确认，不能自动当作 `FAILED` 重试。

## 时间语义

- **所有日志、审计及状态变迁**都有 `occurredAt`/`timestamp` UTC ISO 8601（如 `2026-11-10T13:45:25.382Z`）。
- `startedAt`、`finishedAt`、`failedAt`、`observedAt` 等分别记录不同事件，不覆盖旧值。
- `mtime` 是文件系统元数据；`savedAt` 是 WeaveSpace 确认持久化成功时间；`detectedAt` 是检测外部变化时间，三者不能互换。
- 单机耗时由单调计时器产生，不由墙钟相减。

## 关系与来源

实体与关系包含 `id`、`kind`、`sourceRefs[]`、`status`（candidate/confirmed/rejected/conflict）、`updatedAt`、`revision`。来源指向可定位的文件版本及具体段落/页/片段，不只记录模型的猜测。

## 兼容性

- 每个可持久化自定义格式包含 `format` 和 `schemaVersion`，升级由所属插件提供迁移器。
- 未知字段优先保留、未知文件优先只读；不能默认覆盖内容。
- Schemas 在 `contracts/schemas/`，仅供早期契约验证；运行时兼容行为要由真实测试证明。
