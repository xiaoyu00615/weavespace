## 关键实测结果

**1 · 根行结构（T-19）** — DOM 实测：

```text
真实模式 rootRows = [
  { text: "▾ 设计资料库", folder: true, depth: 0 },
  { text: "▾ 第二个项目", folder: true, depth: 0 }
]
演示模式 rootRows = [
  { text: "▾ 演示项目 · 雨夜", folder: true, depth: 0 }
]
```

`ProjectList` 中不再存在自绘的 `project__root` 卡片；两种模式都从同一个 `TreeRow`、`depth=0` 出发，
子层共用 `TreeBranch` 的缩进与引导线。

**2 · 全类型展示 + 空目录 + 链接（T-01/T-02/T-21）** — `rowCount=222`，其中
`folder=9 / file=213 / link=1`。同屏可见 `.hidden`、`手册.pdf`、`clip.mp4`、`data.json`、
`LICENSE`（无扩展名）、`notes.txt`、`pic.png`、`README.md`；`空目录` 下显示"空文件夹"；
`linked-out` 是唯一 `tree__row--link`，点击后提示
「linked-out」是链接，不展开也不打开（避免越过项目根），根外的 `secret.txt` 未出现。

**3 · 分页（T-14）** — 真实点击「继续加载」前后：

```text
点击前： 已显示 200 / 2005 项 · 继续加载     rows = 222
点击后： 已显示 400 / 2005 项 · 继续加载     rows = 422
```

服务端 `total=2005`，分页按 `nextCursor` 追加而非替换；UI 没有把 2005 项一次性渲染出来。

**4 · 不支持预览（T-20）** — 点击 `手册.pdf` / `pic.png` 后状态栏显示
「…」此类型暂不支持预览或编辑，仍可在文件树中查看；`tabCount = 0`，
即**没有**错误地进入文本编辑器、没有新建标签。

**5 · 两个项目互不干扰** — 第二个项目根 `第二个项目` 独立展开（`assets` / `b.md`），
状态行分别显示"已加载 217 个条目 · 当前项目"与"已加载 3 个条目"。
