# UI Shell、布局树与插件 Slot

用户草图：`../references/user-ui-wireframe.png`。该图说明布局意图，不规定正式色彩/尺寸。

## 五区结构

1. 左侧全局导航：项目 / 插件 / 诊断（可折叠）。
2. 项目树：文件夹、文件、快速筛选；支持多个项目与虚拟资源。

   **结构约束（UX-02B-TREE / 文档 25 契约 C）**：项目根就是这棵树的**第一级**
   （`depth 0`），与子文件夹使用同一个 `TreeRow`；多个项目根并列，各自独立展开、
   折叠、刷新。Demo / Legacy / Multi 共用同一套渲染路径（`TreeBranch` + `FileTreeRow`），
   差异只在数据来源，不允许再出现"另一套项目卡片"。逐层按需加载，展开目录才取该层；
   所有文件格式、空文件夹、链接都要显示，链接只显示不跟随。
3. 顶部上下文工具栏：由当前活动视图/编辑器能力提供，不是每种格式硬编码。
4. 主工作区：标签页 + 可拆分的 Editor / Preview / Canvas / File / Plugin Views。
5. 可折叠辅助面板：图片排列、终端（受控）、AI、错误、任务进度等由插件注册。

## 必须支持的布局

单文件、左右分屏、上下分屏、同文件源码+预览、不同文件并列；初期实现小规模布局树/可调整比例，未来多层嵌套和自由停靠先留布局模型，不必首版实现。

## View 与 Document 的关系

- `ViewInstance(viewId, resourceId?, editorKind, paneId, localViewState)` 为展示实例。
- `DocumentSession(sessionId, resourceId, revision, dirty)` 是共享编辑状态，视图不得直接重复打开第二份来源缓冲。
- `LayoutTree` 只持久化 pane/tab 比例、活动视图及可恢复引用；不复制源文件正文。
- 布局关闭/切换不允许绕过未保存提示；UI 视图崩溃不应使 Document Session 自动作废。

## 动态插件 Slot 候选

`navigation.sidebar`, `project.tree.actions`, `document.toolbar`, `workspace.editor`, `workspace.preview`, `workspace.bottomPanel`, `workspace.contextPanel`, `statusbar.items`。Slot 需声明 cardinality、owner、priority、scope 和卸载清理语义，防止同一插件覆写整片 UI。

## 与外部 AI 的接口

`workspace.openView`, `workspace.split`, `workspace.moveView`, `workspace.resize`, `workspace.saveLayout` 作为 Command/Query 契约；AI 只能操作获授权工作区，不允许 UI 通过命令隐式提升文件读写权限。

## 可访问性与布局恢复

键盘导航、缩放、最小面板宽度、焦点恢复、分屏拖动辅助；不同设备分辨率恢复时裁剪布局并回退为安全单视图，而不是产生不可见文档。
