# 产品范围、用户故事与非目标

## 产品一句话

在一个文件驱动的工作台中，用户通过插件浏览/编辑/关联项目资源；AI 经过授权可在选区、文件、文件夹或项目范围内查询和操作。无需 AI 时软件仍能正常工作。

## 核心用户故事

- U01：添加本地项目根目录，安全发现文件，按类型选择 Viewer / Editor。
- U02：打开 Markdown 左右分屏，左编辑右预览，无需保存即可同步预览；保存明确可追溯。
- U03：打开图片资源，通过图片插件缩放预览；不能因为“可预览”而默认支持原图修改。
- U04：打开 `.wcanvas` 关系图，新增/移动节点、创建连线、布局、保存、重开保持状态。
- U05：使用当前选区与 AI 对话并预览修改；明确选择文件/文件夹/项目扩展作用域。
- U06：文件移动或重命名后，合理保留稳定引用；无法判定时提示待确认。
- U07：插件异常时定位错误与时间，保护未保存工作；必要时安全模式启动。
- U08（未来）：同一局域网另一个浏览器获得限定资源的只读权限。
- U09（未来）：用同一 SSH/GitHub 账号在多设备继续开发，并迁移项目便携配置。
- U10（未来）：从 GitHub / 云存储提供者打开文件，不重写 Markdown 编辑器。

## 阶段边界

**P0 工程原型**：Contracts + Headless Core 的最小命令路径 + Markdown / Image 插件加载 + 文档会话 + 简单分屏 + 结构化日志 + 保存冲突测试。

**V0.1 最小可用工作台**：加入项目树、可恢复布局、自定义画布插件、安全恢复、可定位诊断；原生本地文件为主。

**V0.2+**：项目索引、知识关联、AI 单文件/选区操作、Git 集成、跨文件审批、LAN 与 MCP 适配（按实际优先级迭代）。

## 明确非目标（防范围膨胀）

- 不承诺“所有文件均可无损编辑”；未知格式只读或使用通用查看器。
- 不首版实现自动理解全部视频/图像、PSD/BLEND 等专业格式、3D 编辑、多人实时共编、插件市场。
- 不开发新的完整 Agent Framework；可用外部 AI 调用已注册能力。
- 不从 Work Relay/Local Agent Hub 复制整套状态机或安装逻辑。
- 不依赖 Git 同步运行数据库、密钥、未提交的用户文件，也不让远程用户直连 SQLite 文件。
- 不默认为项目目录所有文件构建云端索引或自动上传外部模型。

## 第一版真实样本

影视项目《向前一步》作为功能验收主题（剧本/人物小传/图片/资产清单/关系画布）。真实私有资产应由用户在自己电脑上加入测试，默认不纳入公开 Git 仓库；工程包仅使用虚构的结构化示例。

## 产品成功指标（测试可测）

1. P0 样本的读取、编辑、保存、冲突拒绝、恢复路径均有可重复测试。
2. 安装一个新的同类文件处理插件，无需修改 Shell 和 Core 的业务代码。
3. 不使用 AI 时，自定义画布仍可保存与重开。
4. 对同一内容反复分析时，缓存行为和模型费用可观测、可解释。
5. 失败能从 traceId 找到具体步骤，而非依靠 AI 猜测。
