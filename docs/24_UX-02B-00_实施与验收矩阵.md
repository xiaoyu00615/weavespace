## 1. 目标与非目标

**目标（用户可直接在网页完成）**：添加本机文件夹 → 本机选择器确认 → 立即出现目录树（无需重启）→ 重命名显示名 → 从工作台移除（不动磁盘）→ 重启后恢复已授权列表。

**非目标（本轮明确不做）**：文件系统监听、后台轮询、自动合并、会话回收（A2）、rebind（A2）、跨平台原生选择器、把子目录自动注册为项目、网页内输入路径。

## 6. 环境约束与已知风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| Windows `TMP` 8.3 短路径 | 全量测试出现假失败（既有问题） | 跑测前 `export TMP/TEMP/TMPDIR` 为长路径 |
| PowerShell 被 EDR 拦截 | 选择器不可用 | 501 + 提示静态模式；`stdin-prompt` 兜底 |
| `FolderPicker` 无法自动化 | "点按钮 → 弹窗"这一层只能人工/浏览器验证 | 测试注入 fake picker；UI 层人工验收 |
| 沙箱禁止 spawn | 测试环境无法真启 PowerShell | Picker 适配器只在生产路径启用，测试走 fake |
| 移除与 Shell 队列竞态 | 可能误判"没有未同步字节" | 首版要求 `openSessions === 0`，不依赖计数 |

## 7. 尚未实现的功能边界（批准后仍需逐项确认）

1. **rebind / adopt**：根被移动后只能重启并重新添加，不自动接管（A2）。
2. **会话回收**：移除后的 STALE 会话保留至视图关闭或进程退出（A2 才有回收）。
3. **逐标签恢复**：首版项目集合变化只恢复 UI，标签不自动认领。
4. **草稿批量导出**：只提供单标签 `GET /api/document` + UI 手动保存。
5. **配置加密与迁移工具**：v1 → v2 只在变更时写回，无单独迁移命令。
6. **多 Host 协同**：`workspace.lock` 只防同机双实例，不做分布式一致性。
7. **非 Windows 原生选择器**：首版仅 Windows；其他平台走 stdin 或静态模式。
