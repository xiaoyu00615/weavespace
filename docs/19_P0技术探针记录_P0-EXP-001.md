## 5. 已知限制与 NOT_RUN（不得当作已实现）

- **NOT_RUN**：localhost HTTP/Gateway、任何 UI 与分屏、SQLite、Cordis 探针、LAN、MCP/外部 AI、Docling、大文件性能基准、`watch` 文件监听、多用户/真实 ACL。
- 插件同进程执行，**无沙箱、无资源限额、无超时终止**；`try/catch` 不是隔离（RSK-13）。
- 幂等收据、Resource ID 映射均在内存：重启后失效（RSK-08/RSK-09）。
- 会话缓冲无草稿恢复区：进程退出即丢失（docs/06「恢复策略」未实现）。
- 版本 token = 内容 SHA-256，大文件成本未测（RSK-06）。
- 类型只做「剥离」不做类型检查：本轮零依赖，未引入 `tsc`（ADR-010 待定，未安装依赖）。
- 直接调用 `document.save`（不经 Command Bus）时事件 `traceId` 为 `trace-unbound`；经 Bus 时正常继承。
- `document.save` 的授权范围取 payload 的 `path`；`applyEdit/save` 仅传 `sessionId` 时按项目根判定，粒度不足。
